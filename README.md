# Ihya Socials (Static Site)

This repo is a simple static site split into separate files:

- `index.html`
- `styles.css`
- `script.js`

## Local Dev (Auto Reload)

Requires Node.js (works with Node 16+).

Run:

```sh
npm run dev
```

Open:

- http://127.0.0.1:3000

Edits to `index.html`, `styles.css`, or `script.js` will auto-reload the page.
